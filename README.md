# Hassan & Nadine — Wedding Invitation 🤍

دعوة زفاف حسن ونادين يوم السبت ٢٨ نوفمبر ٢٠٢٦ في دار المشاة، القاهرة. واجهة عربية وإنجليزية بالصور والموسيقى، مع تأكيد حضور وتهانٍ محفوظة.

## النشر على GitHub Pages

1. ارفع المشروع إلى repository مستقلة Public، والفرع الرئيسي `main`.
2. من Settings → Pages، اختر GitHub Actions كمصدر للنشر.
3. شغّل `Publish wedding invitation` من Actions، أو ارفع تعديلًا جديدًا.
4. رابط الدعوة يظهر في Settings → Pages بعد نجاح النشر.

المستودع: `ahmedDoaia10/Hassan-Nadeen-Wedding`. رابط GitHub Pages عند تفعيل النشر: `https://ahmeddoaia10.github.io/Hassan-Nadeen-Wedding/`.

الاسم الذي تختاره للمستودع يظهر بعد اسم حسابك في الرابط. يمكن ربط دومين تملكه من إعدادات Pages؛ بعدها تستخدم عملية النشر عنوان الدومين نفسه تلقائيًا.

## روابط المشاركة والصورة

عملية GitHub Actions تقرأ رابط Pages الفعلي وتضعه تلقائيًا في بيانات معاينة واتساب والصورة وروابط المشاركة. لا تحتاج كتابة اسم الحساب داخل الكود.

الملفات الأصلية داخل `public/`، والمجلد `dist/` يتولد أثناء النشر. صورة المشاركة هي `public/assets/photos/hassan-nadine-share.jpg`، وهي نفس صورة العروسين الأساسية.

لا توجد صفحة `/invite/` إضافية؛ رابط المشاركة يفتح الدعوة الرئيسية مباشرة.

## الردود والتهاني

GitHub Pages يستضيف الواجهة والصور والأغاني. الحفظ وعرض التهاني يستخدمان خدمة الردود الحالية، مع الاحتفاظ بالبيانات الموجودة.

عنوان خدمة الحفظ مثبت في `RSVP_API_BASE` داخل `public/guestbook.js`، وهو مستقل عن عنوان الدعوة الذي يظهر للناس. لا توجد مفاتيح سرية أو كلمات سر في الواجهة.

الاسم والتهنئة يظهران للجميع. الحضور وعدد الأشخاص لا يعرضان في قسم التهاني. بعد نجاح الإرسال تختفي الاستمارة من نفس المتصفح وعلى نفس عنوان الموقع. الانتقال لدومين مختلف أو مسح بيانات المتصفح قد يعرض الاستمارة من جديد.

## التعديل

- `public/index.html`: الأقسام والنصوص وبيانات المعاينة.
- `public/styles.css`: التنسيق والكمبيوتر والموبايل.
- `public/app.js`: اللغات والأغاني والناف بار والصور والمشاركة.
- `public/guestbook.js`: التسجيل والتهاني واستعادة تأكيد الإرسال.
- `public/assets/`: الصور والأغاني والخطوط.
- `scripts/build-pages.py`: تجهيز روابط الاستضافة الفعلية قبل النشر.

الصور والأغنيتان هما الملفات المرفقة للدعوة. تراخيص الخطوط وتفاصيلها في `FONT-LICENSES.md`.
